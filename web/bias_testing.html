Bias Testing — Demographic Variant Robustness

This is neither Human–LLM Alignment nor Cross-Model Agreement. For a fixed set of moral scenarios, the same story is rewritten with different names (e.g. Male/Female, or Indian/European/American), with everything else — the moral content of the scenario — held constant. This checks whether one model's own valence score for the same scenario shifts just because the demographic marker changed, using a paired Wilcoxon signed-rank test. It never reads human annotations.

Requires a completed evaluation for this model/dataset (run above, or previously run). A low p-value (< 0.05) means the model's scores shifted systematically between the two variants; a high p-value means no bias was detected at this sample size — not proof of its absence, given these datasets are only a few dozen scenarios each.
