A real LLM (Gemini) autonomously chains MCP tools — run evaluation, compute alignment metrics, read the reasoning behind the worst-divergence cases — and writes a report. Nothing about the analysis steps is scripted; the agent decides what to investigate.

Running the entire dataset across multiple models can take a long time and consumes real API quota for every scenario — there is no progress bar while the agent works.
